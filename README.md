# 📈 Tesla Stock Price Predictor

A machine learning application built in **Python** to analyze historical Tesla (`TSLA`) stock market data and forecast price trends using **Linear Regression** and **Random Forest** models.

---

## 📂 Repository Contents

* **`stock price predictor.ipynb`** — Jupyter Notebook covering exploratory data analysis (EDA), feature engineering, model training, and performance evaluation[cite: 30].
* **`stock_price_predictor_app.py`** — Interactive web application script for generating real-time stock price predictions using the trained model[cite: 30].
* **`model.pkl`** — Serialized pre-trained machine learning model ready for inference[cite: 30].
* **`TSLA.csv`** — Historical Tesla stock dataset (Open, High, Low, Close, Volume) used for training and testing[cite: 30].

---

## 🛠️ Tech Stack

* **Language:** Python
* **Machine Learning & Data:** Scikit-learn, Pandas, NumPy
* **Visualization & App:** Matplotlib, Jupyter Notebook

---

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/prageeshjaiin/stock-market-predictor.git](https://github.com/prageeshjaiin/stock-market-predictor.git)
   cd stock-market-predictor
   ```

2. **Install required dependencies:**
   ```bash
   pip install pandas numpy scikit-learn matplotlib streamlit
   ```

3. **Run the prediction app:**
   ```bash
   streamlit run stock_price_predictor_app.py
   ```
   *(If your script uses Flask or standard CLI execution, run `python stock_price_predictor_app.py` instead.)*
